# DeepWiki Redirect

A Chrome extension that automatically redirects GitHub repository pages to [DeepWiki](https://deepwiki.com).

## Usage

Visit any GitHub repository page (e.g., `https://github.com/facebook/react`) — the extension redirects to `https://deepwiki.com/facebook/react`.

Click the extension icon to toggle on/off:

| State | Icon |
|-------|------|
| Enabled | ![](icon) |
| Disabled | ✕ badge |

## Install

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked** and select this directory
